HOW IT WORKS

A dataset you can trace

  1. Find a player

    Use your Riot ID or an active Top player’s ID. You don’t need to play new games.

  2. Collect ranked history

    Only Solo/Duo games with an identified Top on each team are saved. Existing records are skipped.

  3. Inspect a matchup

    Open a pair in the explorer, then fetch timelines for early-lane snapshots.

To examine the next 100 older games, set the offset to 100. A tag alone doesn’t identify the player’s routing region.

Riot Games API

Used for ranked history and timelines. Set RIOT_API_KEY in backend/.env and restart the app.

Development keys expire after 24 hours. Never paste a key into chat or commit it.

OpenAI coaching

Set OPENAI_API_KEY in backend/.env and restart. Set OPENAI_MODEL to override the model.

Reports work without this connection. A configured key still needs valid API access and billing.

About your evidence

LaneCoach records final game outcomes and optional timeline snapshots. It does not know a player’s rank, wave state, or the cause of a lead. Selected-player samples can be small and biased. AI advice is a practice aid, not a guaranteed matchup solution.
